# AI Models Directory

Place your LiteRT (.tflite) model files here:

- `all-MiniLM-L6-v2.tflite` — Sentence embedding model for vectorizing notes
- `gemma-2b-it.tflite` — Language model for generating natural language answers

## Download Links

- **all-MiniLM-L6-v2**: Search for "all-MiniLM-L6-v2 tflite" on Hugging Face or TensorFlow Hub
- **Gemma 2B IT**: Available from Google's Kaggle model hub (requires sign-in)

## Note

These files are large (especially Gemma 2B at ~1.5GB+). They are excluded from git via `.gitignore`.
